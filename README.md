# U.J planner

갤럭시 Z 플립7용 주간 자동 배치 플래너. 고정 일정만 사람이 넣고, 가변 일정은 앱이 남는 시간에 알아서 넣는다.
못 한 일정은 앱에 들어올 때 물어보고 이번 주 남은 빈칸에 다시 넣는다. 서버 없이 폰 안에만 저장한다.

이 문서는 **내 폰에 설치하는 방법**이다. 코드 구조와 작업 규칙은 [`CLAUDE.md`](CLAUDE.md)에 있다.

## 준비물

- macOS + JDK 17 + Android SDK (`~/Library/Android/sdk`)
- 폰: Android 11 이상. 갤럭시 Z 플립7(Android 16) 기준으로 만들었다
- USB 케이블 (방법 A) 또는 파일을 폰으로 옮길 수단 (방법 B)

## 1. 릴리스 키 만들기 — 처음 한 번만

```bash
./tools/make-release-key.sh
```

비밀번호를 두 번 묻는다. 끝나면 두 가지가 생긴다.

| 파일 | 위치 | |
|---|---|---|
| 서명 키 | `~/.uj-planner/release.jks` | 레포 밖 |
| 서명 설정 | `keystore.properties` (레포 루트) | gitignore 됨 |

> **키 파일과 비밀번호를 다른 곳에 꼭 백업해 둔다.**
> 키를 잃으면 같은 앱으로 업데이트할 수 없다. 새 키로 만든 APK 는 덮어 설치가 안 돼서 앱을 지우고 다시 깔아야 하고,
> 그때 데이터는 [내보내기·가져오기](#폰을-바꾸거나-앱을-지우기-전에)로만 옮길 수 있다.

## 2. APK 만들기

```bash
./gradlew :app:assembleRelease
```

결과물은 `app/build/outputs/apk/release/app-release.apk` (약 3MB). 첫 빌드는 코드 축소 때문에 10분 넘게 걸릴 수 있다.

`app-release-unsigned.apk` 가 나왔다면 1번을 건너뛴 것이다. 서명 없는 APK 는 설치되지 않는다.

## 3. 폰에 설치

### 방법 A — USB 로 설치 (추천)

폰에서 한 번만 해 둘 것:

1. **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호**를 7번 누른다 → 개발자 옵션이 켜진다
2. **설정 → 개발자 옵션 → USB 디버깅**을 켠다
3. 케이블로 맥에 연결하고, 폰에 뜨는 "USB 디버깅을 허용하시겠습니까?"에서 **허용**

맥에서:

```bash
ADB=~/Library/Android/sdk/platform-tools/adb
$ADB devices                                                   # 폰이 device 로 보여야 한다
$ADB install -r app/build/outputs/apk/release/app-release.apk
```

`Success` 가 나오면 끝. 앱 서랍에 **U.J** 가 생긴다.

### 방법 B — APK 파일을 옮겨서 설치

1. `app-release.apk` 를 폰으로 옮긴다 (Quick Share, 구글 드라이브, 메신저 "나에게 보내기" 등)
2. 폰의 **내 파일** 앱에서 APK 를 누른다
3. "출처를 알 수 없는 앱 설치" 안내가 뜨면 **설정 → 이 출처 허용**을 켜고 돌아와 **설치**

### 설치가 막힐 때

| 증상 | 원인과 해결 |
|---|---|
| 설치 버튼이 없거나 "차단됨" | 삼성의 **보안 위험 자동 차단**이 켜져 있다. 설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단을 끄고 설치한 뒤 다시 켠다 |
| Play 프로텍트 경고 | 스토어에 없는 앱이라 뜨는 경고다. **무시하고 설치** |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 서명이 다른 같은 앱이 이미 깔려 있다(디버그 빌드, 또는 다른 키로 만든 APK). 아래 "디버그 빌드를 깔았었다면" 참고 |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | 깔린 것보다 `versionCode` 가 낮다. 아래 "업데이트" 참고 |
| `adb devices` 에 `unauthorized` | 폰 화면의 USB 디버깅 허용 창에서 허용을 누르지 않았다. 케이블을 다시 꽂는다 |
| `adb devices` 에 아무것도 없음 | 충전 전용 케이블이다. 데이터 케이블로 바꾼다 |

## 업데이트

1. `app/build.gradle.kts` 의 `versionCode` 를 1 올린다 (`versionName` 은 보기용이라 자유)
2. `./gradlew :app:assembleRelease`
3. 방법 A 의 `adb install -r …` 또는 방법 B 로 **덮어 설치**한다

같은 키로 서명했고 `versionCode` 가 올라갔다면 데이터는 그대로 남는다.

## 폰을 바꾸거나 앱을 지우기 전에

데이터는 폰 안에만 있고 클라우드 백업도 꺼 두었다. 앱을 지우면 같이 사라진다.

1. 옛 폰: **설정(톱니) → 데이터 → 내보내기** → `uj-planner-YYYYMMDD.db` 를 저장하고 새 폰으로 옮긴다
2. 새 폰: 앱을 설치하고 **설정 → 데이터 → 가져오기** → 그 파일을 고른다 → 확인하면 앱이 다시 시작되며 복구된다

가져오기는 지금 있는 데이터를 **전부 바꾼다.** 이 앱에서 내보낸 파일이 아니면 거부하고 아무것도 바꾸지 않는다.

## 디버그 빌드를 깔았었다면

`./gradlew :app:installDebug` 로 깐 디버그 빌드와 릴리스 APK 는 서명이 달라 서로 덮어 설치되지 않는다.
실사용 폰에는 **처음부터 릴리스 APK** 를 깐다. 이미 디버그 빌드를 쓰고 있었다면:

1. 디버그 빌드에서 **내보내기**로 데이터를 파일로 빼 둔다
2. 앱을 지운다 (`adb uninstall com.uj.planner`)
3. 릴리스 APK 를 설치하고 **가져오기**로 되돌린다

## 처음 실행하면

1. 빈 그리드 위 카드에서 **고정 일정 추가** — 출근, 수업처럼 매주 같은 시간에 있는 것부터 넣는다
2. **+ 일정 → 가변** — 이름·소요시간·주당 횟수·선호 시간대만 정하면 앱이 이번 주 빈칸에 넣는다
3. **설정 → 배치 가능 시간대** — 요일별로 앱이 일정을 넣어도 되는 시간을 정한다 (기본: 평일 08–24시, 주말 10–01시)
4. 접으면 커버 화면에 "지금 할 일"이 뜨고, 반쯤 접어 세우면 위는 오늘 타임라인·아래는 완료 버튼이 된다
