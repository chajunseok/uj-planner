# U.J planner — 디자인 시안 구현 스펙

Claude Design 프로젝트 `UJ planner - 화면.dc.html`(방향 1a)에서 구현에 필요한 값만 뽑은 문서.
원본: https://claude.ai/design/p/cdc60b48-1c00-4491-920c-ce60adcc7c66
위임 프롬프트는 `260918.uj-planner.design.md`.

라이트 단일 테마. 모든 수치는 dp/sp. 구조·밀도·상태 표현은 방향 1a, 색과 제목 활자는 시안 0-4 「플라워」 조정안
(2026-09-19 사용자 승인)을 따른다. 색은 `ui/theme/` 한 곳에만 있다.

## 50dp 열 밀도 해법

이름 대신 **색 + 앞 2글자**(공백 제거). 고정 일정은 1시간 이상이면 전체 이름. 1행 = 약어 + 12dp 상태 아이콘,
2행 = 9sp 시작 시각(높이 ≥ 44dp일 때만). 탭하면 상세 카드. 세로 쓰기·3일↔7일 전환은 채택 안 함.

## 화면

- **A1 주간 그리드**: 상단 "9월 셋째 주" + "9.14 – 9.20 · 이번 주" + 설정. 배치 실패 배너(44dp, tertiaryContainer, 실패 0이면 안 그림) →
  탭하면 일정별 못 넣은 횟수·조건 요약·`조건 바꾸기`/`다시 짜기`. 오늘 열 강조(날짜 원 primary), 현재 시각선 error. 하단 바: ‹ 이번 주 › + `일정` FAB.
- **A2 이동**: 길게 눌러 드래그. 상단 안내 "운동 · 놓을 자리로 끌어 주세요 / 금 19:00 – 20:00". 하단 `취소` / `이번 주 버림`.
- **A3 빈 상태**: "먼저 움직이지 않는 일정을 넣어 주세요" + `고정 일정 추가` / `가변 일정부터 넣기`.
- **A4 고정 등록**: 이름 · 요일 다중 선택 · 시작 시각(±30분) · 소요시간 칩(30분·1·1.5·2·3시간·직접) · 요약 줄 · 저장 56dp · 삭제.
- **A5 가변 등록**: 이름 · 색 스와치 4×2 · 소요시간 칩 · 주당 횟수 스테퍼 · 우선순위 3칸 · 선호 시간대 4칸(아이콘+글자) · 마감 요일 칩(없음+월~일) ·
  예상 배치 한 줄 · `저장하고 배치`.
- **A6 밀린 일정 시트**(진입 시 자동): "지난 일정 N개, 어떻게 됐어요?" 항목당 했음(filled)·못함(tonal)·버림(outlined), 비율 1.3:1:1, 48dp.
  처리된 항목은 결과 줄("→ 금 08:00으로 옮겼어요" + 되돌리기)로 상단에 쌓임. 하단 `남은 N개 모두 했음` / `나중에`. 오래된 것부터.
- **A7**: 못함인데 빈칸 없음 → 다이얼로그 "이번 주엔 빈칸이 없어요" `이번 주는 버림` / `다시 짜기`. 재배치 성공 시 스낵바 + 되돌리기.
- **A8 설정**: 요일별 시작–종료(자정 넘으면 +1 표시), `월 → 평일 전체`·`토 → 주말` 복사, `이번 주 다시 짜기`, 버전 줄.
- **B 플렉스**: 위 = 요일·날짜·남은 개수 + 오늘 타임라인, 아래 = 지금 카드(kicker·제목·다음) + 완료 56dp / 못함. 밀린 일정 있으면 그 카드 우선, 다 끝나면 "끝!" + `이번 주 보기`.
- **C 커버**: 상단 시각 / 오늘 남은 개수, 중앙 색 점 + kicker 14 + 제목 34 + 부제 16, 하단 완료 64dp + 못함 텍스트 버튼. 지금 없으면 "다음" 카드 + `미리 완료`, 다 끝나면 "끝!".
- **0 아이콘·스플래시**: 적응형 아이콘 — 배경 `#FBF7F2`, 전경 튤립 아트워크 70dp, 단색은 튤립 실루엣 벡터. 스플래시 배경 surface, 별도 애니메이션 없음.
  로딩 전용 화면 없음(계산 100ms 이내).

## 시안과 다르게 가는 것

| 시안 | 구현 | 이유 |
|---|---|---|
| 튤립 전경 1024px 원본에서 5개 밀도 내보내기 | 사용자가 내보낸 432px(xxxhdpi) 한 장만 사용 | 원본 PNG가 가져오기 도구 상한(256KiB)을 넘어 잘림. 432px 이면 가장 높은 밀도라 시스템 축소로 충분 |
| 블록 이동 중 하단 바 `취소` / `이번 주 버림` | 놓을 수 없는 곳에 놓으면 취소, `버림`은 블록 상세 카드에 | 끄는 손가락으로는 하단 버튼을 누를 수 없음 |
| 재계산 중 스켈레톤·진행 바 | 생략 | 시안도 "300ms 넘을 때만 보임"이라 명시. 실측해서 느리면 추가 |
| 스플래시 AnimatedVectorDrawable | 생략 | 시안에서 "선택" |
| 끌기 안내 배너가 배치 실패 배너 자리에 뜸 | 제목 자리(고정 64dp)에 뜸 | 배치 실패 배너가 없는 주에는 그 자리가 비어 있어, 끼워 넣으면 그리드가 밀려 손가락과 블록이 어긋남 |
| 아이콘 Material Symbols Rounded (채움 없음) | `material-icons-extended` 의 Outlined / Rounded 중 가까운 것 | Symbols 폰트를 싣지 않음. `calendar_clock` 은 세트에 없어 `EditCalendar` 로 대체 |
| 글꼴 Pretendard | 기기 기본 글꼴 | 글꼴 파일을 싣지 않음. 실기기(삼성)에서는 어차피 시스템 글꼴이 에뮬레이터와 다름 |
| 재배치 성공 스낵바(A7 아래) | 밀린 일정 시트의 결과 줄 + 되돌리기 | 시트가 열린 채로 결과를 보여 주므로 같은 정보를 두 번 띄우지 않음 |
| 플렉스 "끝" 카드의 `이번 주 보기` / `+ 일정`, 커버 `잘 자요` 버튼 | 생략 | 반 접힌 동안은 항상 플렉스 화면이라 갈 곳이 없고, `잘 자요` 는 동작이 없음 |
| 가변 편집의 이름 칸 높이 48dp | 56dp | Material 입력칸의 최소 높이. 옆의 색 8칸(62dp)과 아래를 맞춤 |
| 「플라워」 5번: 그림자 색 온도(갈색 그림자) | 생략 | Compose 기본 그림자는 elevation 으로 그려 색을 바꾸려면 모든 Surface 에 색을 따로 줘야 함 |
| 「플라워」 세리프 Noto Serif KR | 기기에 든 세리프(Noto Serif CJK) | 글꼴 파일을 싣지 않음. 실기기에서 어긋나면 `res/font` 에 추가 |

## 개정 이력

- 2026-09-19 · 시안을 렌더링해 앱 화면과 나란히 비교. 첫 구현은 색·치수 토큰만 옮기고 컴포넌트는 Material 기본 모양(알약 버튼, 채운 아이콘, 각진 입력칸, 세로로 늘어놓은 폼)을 그대로 써서 시안과 달랐음. 공용 컨트롤을 시안 모양으로 다시 만들고 전 화면을 맞춤. 남은 차이는 위 표에 기록.
- 2026-09-19 · 0-4 「플라워」 조정안 승인. 색 토큰·일정 팔레트·반경·세리프 제목 반영.
